# Technology Commons emblem assets

This branch is intentionally scoped to the generated Technology Commons lighthouse emblem only.

## `emblem/`

The emblem contains the lighthouse and AA structure, gold growth/leaves and roots, blue waves, and circular frame.

Included assets:

- `commons-emblem.svg`: canonical full-colour vector
- `commons-emblem-transparent.png`: full-colour PNG on transparent background, 1024x1024
- `commons-emblem-white-background.png`: full-colour PNG on white, 1024x1024
- `commons-emblem-monochrome-blue.svg`: one-colour navy vector
- `commons-emblem-monochrome-blue-transparent.png`: navy PNG on transparent background
- `commons-emblem-monochrome-blue-white-background.png`: navy PNG on white
- `commons-emblem-monochrome-light.svg`: one-colour off-white vector using `#FAF7F2`
- `commons-emblem-monochrome-light-transparent.png`: off-white PNG on transparent background
- `commons-emblem-monochrome-light-white-background.png`: off-white PNG on white
- `commons-emblem-monochrome-light-navy-background.png`: off-white PNG on navy for practical dark-background use
- `commons-emblem-fabrication.svg`: simplified single-colour fabrication vector
- `commons-emblem-fabrication.dxf`: CAD/fabrication outline export

## Colours

- Commons navy: `#062650`
- Commons gold: `#D49A00`
- Light/off-white: `#FAF7F2`
- White: `#FFFFFF`

## Fabrication

Use the monochrome or fabrication versions for vinyl cutting, laser cutting/engraving, signage, CAD import, or as a starting profile for an Onshape stamp. The SVG files contain vector geometry rather than embedded raster images.

The full-colour emblem should be used where colour and detail can be retained. The monochrome/fabrication versions are intended for manufacturing processes where a single positive/negative shape is more reliable.
